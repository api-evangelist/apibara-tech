# Apibara.tech

Developer platform offering a normalized JSON API over Copart and IAA/IAAI vehicle auction records — current inventory, retained auction/sale history, VIN and lot details, pricing, auction status, locations, shipping estimates, and source-provided media. Not affiliated with the blockchain indexer at apibara.com.

## APIs

- **Vehicle Auction Data API** — REST/JSON API over Copart & IAAI vehicle auction data with API-key auth. Endpoint groups include Vehicles, Vehicle History, Related Vehicles, Filters, Locations, Shipping, URL Tools, Usage, and Image Proxy. Also exposes a hosted read-only MCP server and llms.txt for agents. (`https://apibara.tech/api/v1/vehicle-auction`)

> Multiple public interfaces confirmed: REST/JSON API (X-API-Key auth), hosted read-only MCP server at https://apibara.tech/mcp (MCP-Protocol-Version 2026-07-28), llms.txt + llms-full.txt, OpenAPI 3.1 & 3.0.3, Postman collection, and a self-published apis.json (https://apibara.tech/apis.json). Arazzo workflow files (incremental-sync, vin-research) exist under https://apibara.tech/ai/workflows/ but there is no schema property type for Arazzo, so they are noted here. No GraphQL or AsyncAPI is offered. No formally published agent-skills package exists. Code examples repo: https://github.com/apibara-tech/apibara-vehicle-auction-api-examples.
