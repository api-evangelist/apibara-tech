# Apibara.tech

Independent developer platform providing structured vehicle auction data (normalized JSON for Copart and IAA/IAAI current and historical auction records), including vehicle search, VIN/lot details, photos, prices, sale history, filter metadata, auction locations, shipping calculation, and an image proxy. Offers both a REST/JSON API and a hosted read-only MCP server. Not affiliated with the similarly named apibara.com blockchain indexer.

## APIs

- **Vehicle Auction Data API** — REST/JSON API providing normalized Copart & IAAI vehicle auction data: vehicle search, VIN/lot details, vehicle history, related vehicles, filters, auction locations, shipping calculation, URL tools, usage, and image proxy. Authenticated via X-API-Key header with cursor-based pagination. A hosted read-only MCP server exposes 8 agent tools mapped to this API. (`https://apibara.tech/api/v1/vehicle-auction`)
