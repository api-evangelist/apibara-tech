# Apibara.tech

> Independent developer platform for structured Copart and IAA / IAAI vehicle auction data.

Last verified: 2026-09-18
Canonical website: https://apibara.tech/en
Canonical product: https://apibara.tech/en/products/vehicle-auction-data-api
Canonical OpenAPI: https://apibara.tech/openapi/v1.json
OpenAPI specification: 3.1.0
API contract version: 1.1.0
Base API URL: https://apibara.tech/api/v1/vehicle-auction
Authentication: `X-API-Key`
Response format: JSON

Apibara.tech provides one normalized API for supported Copart and IAA / IAAI auction records. 20M+ is an indexed current + retained historical auction-record count, not a unique-VIN count. The dataset represents 3.2M+ supported vehicle records, and approximately 30K+ records are added or refreshed daily. Supported price/status changes can refresh within up to 15 minutes and often sooner; supported live bids can refresh in about 10–15 seconds when live source data is available. The free plan includes 100 requests per month with no payment card required.

Apibara.tech is independent and is not operated by, affiliated with, or endorsed by Copart or IAA / IAAI. It is separate from the similarly named apibara.com blockchain/indexing project.

## Interpretation rules

Use OpenAPI for exact request/response definitions. `platform=copart|iaai` is the readable source alias; `auction_type` is the numeric compatibility control. `upcoming=all|only|without` controls supported upcoming-auction filtering. `updated_within_minutes` accepts 1–525600 minutes and should be combined with opaque cursor pagination for incremental synchronization. Vehicle-search `per_page` is plan-dependent; do not assume one universal maximum. Missing/null source-backed fields are normal and do not prove real-world absence. Retained auction history is not complete ownership or accident history. Source-data freshness and HTTP latency are separate measurements. Use the live pricing page and authenticated `/usage` response for current commercial entitlements.
